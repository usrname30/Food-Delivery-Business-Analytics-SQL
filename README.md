# Food Delivery Business Analytics using SQL

## Project Overview
This project analyzes food delivery business data using MySQL. It focuses on customer behavior, restaurant performance, delivery operations, payment trends, and business KPIs.

## Tools Used
- MySQL Workbench
- SQL
- GitHub

## Dataset
Food Delivery Orders Dataset
